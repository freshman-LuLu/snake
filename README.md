## 🐍 version 1

### 利用ai编写的代码

1.**游戏状态控制**：通过全局变量 `gameOver` 控制游戏状态，当其值为真时，游戏循环结束。

### 📝 逻辑实现

1. **蛇身数据结构**：利用数组 `snakeX[100]` 和 `snakeY[100]` 存储蛇身坐标，理论上限为 101 节。
2. **游戏状态控制**：通过全局变量 `gameOver` 控制游戏状态，当其值为真时，游戏循环结束。
3. **初始化逻辑**：通过初始化 `snakeX/Y` 数组和方向变量 `dir`，设定蛇的初始长度与默认移动方向。
4. **食物生成**：利用 `rand()` 函数随机生成食物坐标。
5. **画面绘制**：利用双重循环构建游戏边框，并判断坐标 `(x, y)` 与 `snake` 数组的匹配情况，决定绘制空格还是蛇身。渲染优先级为：**蛇头 > 食物 > 蛇身**（避免与蛇身重合）。
6. **键盘输入控制**：利用 `_kbhit()` 检测键盘输入，通过 `_getch()` 获取输入字符，配合 `if` 判断和 `switch-case` 结构实现蛇的转向。
7. **移动实现**：通过循环 `snake[i] = snake[i-1]`，让后一节蛇身占据前一节的位置，实现蛇的移动逻辑。
8. **蛇头移动**：利用 `dir` 变量的值对应不同的自增/自减运算，实现蛇头坐标的定向更新。
9. **碰撞与吃食判定**：通过 `if` 结构判断蛇头坐标是否与墙体、自身或食物重合。若撞墙或撞自己则游戏结束；若吃到食物则长度加一，并重新随机生成食物。
